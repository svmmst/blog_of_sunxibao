## 🏛 项目架构

本博客采用现代化的**极简无服务器静态架构**：

- **托管服务**：Cloudflare Pages（全球 CDN 边缘节点秒开、免费 SSL 加密）
- **发布机制**：GitHub + Cloudflare 自动持续集成（CI/CD）
- **写作解耦**：所有随笔文章保存在 `posts/` 目录中，支持标准 Markdown 格式
- **构建引擎**：纯原生 Node.js 静态编纂脚本（`build.js`），零臃肿依赖，编译耗时 < 0.1 秒

## ✍️ 如何撰写与发布新随笔？

### 1. 新建文章
在 `posts/` 目录下新建一个 `.md` 文件（如 `05-初冬围炉试新茶.md`），在开头注明文章元信息：

```markdown
---
title: 初冬围炉试新茶
date: 甲辰年十月初五 · 立冬后
solar_term: 立冬
month_tag: 甲辰年十月
category: 闲读偶得
order: 0
---

这里直接写你的正文内容。

每个空行自然成为一个段落。文字排版会自动套用宣纸水墨宋体设计……
```

### 2. 本地测试与发布
在终端运行：

```bash
# 1. 自动编译生成新版网页
node build.js

# 2. 提交并推送到 GitHub
git add .
git commit -m "feat: 发布新随笔《初冬围炉试新茶》"
git push
```

**推送完成后，Cloudflare Pages 会在 10 秒内自动捕捉更新并全网同步上线！**
